# MIND GARDEN

גינה אישית למחשבה: אפליקציית טלפון בעברית, עם פעילויות קצרות לזיכרון, לקשב ולשפה.

זו תשתית שלב 0 (לפי מסמך האפיון, חלק 1): הממשק, הניווט, שמירת הנתונים ומשחק לדוגמה אחד (גן הזוגות). שאר המשחקים מופיעים בקטלוג כ"בקרוב" ועוד לא נבנו.

## הפעלה

```bash
npm install
npm run dev          # פיתוח: http://localhost:5173
npm run build        # בדיקת טיפוסים ובנייה לתיקיית dist
npm run preview      # הרצת הבנייה, גם מטלפון באותה רשת (--host)
npm test             # בדיקות יחידה ובדיקות ממשק (Vitest)
npm run check:rtl-i18n   # אוכף RTL וטקסטים מקובצי התרגום בלבד
npm run smoke        # בדיקות בדפדפן אמיתי, במסכי iPhone ו-Android (דורש Chrome)
npm run icons        # יצירה מחדש של אייקוני האפליקציה
```

| ממשק | React 18 + TypeScript במצב strict | |

## מבנה הפרויקט

```text
src/
  core/                 לוגיקה שלא תלויה ב-React (ניתנת לשימוש חוזר בכל פלטפורמה)
    adaptive/           מנוע התאמת קושי (שיטת מדרגות, יעד של כ-80% הצלחה)
    games/              קטלוג המשחקים וטיפוסים
    garden/             חישוב הגינה ו-7 הימים האחרונים מתוך הפעילויות
    memories/           זיכרונות מוצפנים (טקסט ותמונה)
    routine/            השגרה היומית
    settings/           הגדרות נגישות ושמירתן
    sound/ speech/      צלילים עדינים (Web Audio) והקראה (Web Speech)
    storage/            IndexedDB, הצפנה, התקדמות, ייצוא ומחיקה
    time/               תאריכים בעברית
  games/                משחק = מודול עצמאי
    registry.ts         מיפוי מזהה משחק לרכיב (נטען רק כשמשחקים בו)
    memory-pairs/       גן הזוגות: לוגיקה טהורה, איורים, רכיב
  i18n/locales/he/      כל הטקסטים בעברית
  screens/              מסכי האפליקציה
  ui/                   רכיבים משותפים ואייקונים
  styles/               טוקנים מהעיצוב (חלק 2), רק תכונות לוגיות (start/end)
scripts/                בדיקות, יצירת אייקונים
```

## הוספת משחק

1. רשומה ב-`src/core/games/catalog.ts`, עם `status: 'available'`.
2. טקסטים תחת `games.<id>` בקובץ `src/i18n/locales/he/games.json`: כותרת, תיאור וצעדי הוראות בשלוש צורות פנייה.
3. תיקייה `src/games/<id>/` עם רכיב שמממש את `GameProps` (מתוך `src/games/types.ts`), ושורה אחת ב-`registry.ts`.

המשחק לא ניגש לאחסון בעצמו. מארח המשחק (`PlayScreen`) שומר כל מהלך, מתעד את הפעילות בסיום, מתאים את הרמה הבאה ושותל צמח.

## הוספת שפה

תיקייה `src/i18n/locales/<lang>/` עם אותם מפתחות, רישום ב-`SUPPORTED`, ותוכן משחקים שנכתב מחדש לשפה (לא תרגום ישיר). כל העיצוב משתמש בתכונות לוגיות, ולכן כיוון LTR יעבוד בלי לשנות CSS. אייקונים כיווניים מסומנים ב-`flip-ltr`.

## פרטיות ואבטחה

- אין שרת, אין חשבון, אין אנליטיקה ואין פרסומות. מדיניות CSP חוסמת כל בקשה לצד שלישי.
- תוכן הזיכרונות מוצפן במכשיר. המפתח נוצר כ"לא ניתן לייצוא" ולכן אף סקריפט לא יכול לקרוא אותו. מגבלה: מי שמחזיק בטלפון פתוח ובדפדפן יכול עדיין לצפות בזיכרונות דרך האפליקציה.
- האפליקציה מבקשת מהדפדפן אחסון קבוע, כדי שהנתונים לא יימחקו מעצמם.
- בהגדרות יש ייצוא של כל הנתונים ומחיקה מלאה שלהם, כולל מפתח ההצפנה.
- ציון ההצלחה במשחק משמש רק להתאמת הקושי, ולא מוצג למשתמשת.

## מגבלות ידועות

- ב-iPhone ההתקנה נעשית ידנית: כפתור שיתוף ב-Safari ואז "הוספה למסך הבית". המסך מסביר את זה. ב-Android ובדפדפני Chrome מופיע כפתור התקנה.
- ההקראה תלויה בקול העברי שמותקן בטלפון. אם המכשיר לא תומך בהקראה, הכפתורים שלה לא מוצגים.
- ב-iPhone, נתונים של אתר שלא הותקן במסך הבית עלולים להימחק אחרי תקופה ארוכה בלי שימוש. לכן מומלץ להתקין.
